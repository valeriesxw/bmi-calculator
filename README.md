# BMI Calculator

A simple BMI calculator built with HTML, CSS and JavaScript.

## How to use
Open `index.html` in your browser, enter your weight (kg) and height (cm), and click **Calculate**.

## BMI categories
| BMI | Category |
|-----|----------|
| Below 18.5 | Underweight |
| 18.5 to 24.9 | Normal weight |
| 25 to 29.9 | Overweight |
| 30 and above | Obese |
